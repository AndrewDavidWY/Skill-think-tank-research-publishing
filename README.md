# 智库专题研究与内容发布

把历史资料作为选题线索，重新研究经典企业理论，形成适合经营者和团队分析、决策与执行的内容。优先研究经典理论面向《利益相关者资本论》的升级，逐项建立依据、方法与验证办法。

本仓库提供可供 Codex 使用的 Skill。研究资料、书稿全文、账号配置和网站源码不包含在内。Skill 源文件为中文；网站上的其他语言介绍不代表已有相应语言的 Skill 源文件。

## 使用

下载本仓库，将包含 `SKILL.md` 的文件夹命名为 `think-tank-research-publishing`，放入本机 Codex 的 `~/.codex/skills/`，重新打开会话后使用 `$think-tank-research-publishing`。也可以直接让支持读取本地 Skill 的工具按仓库内 `SKILL.md` 工作。

例如：

> 用 $think-tank-research-publishing 梳理这批资料。先列选题，优先选择与利益相关者资本论最直接相关的经典理论，暂不写文章。

> 用 $think-tank-research-publishing 研究这个选题，核实原理论及当前证据，提出升级机制并绘制 SVG。只交付中文稿和研究底稿。

> 用 $think-tank-research-publishing 将已确定的稿件接入网站，检查正文、配图、来源和语言状态，提交独立 PR，暂不上线。

## 工作原则

- 保留经典理论仍有效的部分，具体研究可以补足或调整的机制。
- 原理论、已有证据、新推论与待验证假设分清楚；不预设升级效果已经成立。
- 面向读者提供完整实用内容，不讲内部整理经历和改稿经过；必要出处仍保留。
- 不把重写、翻译或重绘当作理论原创，不强行给每个工具增加资本安排。
- 用户决定本次工作阶段；只要选题就停在选题，发布按当次授权和实际项目执行。

入口见 [SKILL.md](SKILL.md)。批量资料、理论升级和网站交付分别按需读取 `references/` 内对应文件。
