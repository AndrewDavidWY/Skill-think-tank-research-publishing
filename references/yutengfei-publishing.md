# yutengfei.com 网站适配

仅在该站内容接入、维护、PR 或上线任务中读取。这里描述适配方法；字段、路由和部署状态以本次真实项目为准。

## 修改前核实

读取项目 AGENTS、README 和内容说明，检查当前分支、未提交文件与远端状态。按项目要求实时取得 GitHub 最新主分支，保留编辑、配置和素材，再选择隔离工作区。不要用旧预览目录代替最新源码。

检查智库当前的 Keystatic 配置、内容文件、渲染器、分类、搜索索引和译审流程。内容管理界面中的字段与最终页面不一定一一对应，沿真实数据流确认。既有地址可以继续服务同一主题时优先保留，不为改标题重建链接。

## 写入与验证

- 将完整正文写入当前内容源；标题、摘要和搜索结果不能承诺没有开放的全文。
- 分类和专题按内容本身选择；人工关联只连接确实相关的文章、论文和书章，不用不相关文章填补空入口。
- 署名、引用、贡献与转载来源分别表达，不因整理或发布就把外部经典理论标为原创。若跨站发布，核对作者链接、原文链接和双方实际页面。
- 检查图片资源路径、SVG 字体回退、暗色与浅色表现、手机宽度、目录、表格和外链。
- 翻译任务按当前站点语言及排序执行。若仍使用中、英、日、韩、泰、越南、印尼七种语言，逐一检查本地化正文、摘要、路由及审核状态；不要把界面翻译等同内容翻译。用户限定中文版时不扩展到其他语言。
- 运行相关内容校验、测试和构建，核查真实生成的页面与搜索入口。没有运行的检查不能报通过。

## 交付状态

按用户授权完成保存、PR、合并或上线，不把某一阶段默认扩成后续全部操作。PR 包含具体内容、必要配图、来源和验证说明，不能只有发布计划。

本地保存、预览更新、GitHub 提交、合并和 OSS 发布各自核实。只有正式地址读取到相应新版本时才称上线完成。部署配置不可访问时先完成可执行范围，说明缺少哪一环以及由谁继续；不要求用户在聊天中提供密钥。
